Upgrading to 1.3.0

A feature release with a few changes an existing install relies on.

  • ClamAV is opt-in in Docker Compose
  • Signup asks for name and password at verification
  • The audit log is readable, and kept by default

Upgrading to 1.2.0

A security release that changes behaviour you may be relying on. Read before upgrading.

  • Credentials made in the 1.1.1 UI stop working
  • Everyone is signed out once
  • Email no longer carries ticket content
